# wat

`wat` is a terminal assistant with an inline, differential renderer.

## Features

- Interactive terminal assistant
- Streaming responses
- Tool execution (bash and other tools)
- Incremental rendering with cursor/viewport handling
- tmux-friendly behavior

## Build

```bash
cargo build
```

## Run

```bash
cargo run
```

## Test

```bash
cargo test
```

## Install

```bash
cargo install --path .
```

## Notes

- Use `Ctrl+C` to exit.
- Type `clear` to clear conversation history.
- Type `exit`, `quit`, or `q` to quit.
